# CMS Dashboard

Learning project based on the [Next.js App Router course](https://nextjs.org/learn). It is a TypeScript dashboard with authentication, Postgres, and Tailwind CSS — useful for App Router practice, not a production CMS.

**Live demo:** [nextjs-dashboard-imiantalha.vercel.app](https://nextjs-dashboard-imiantalha.vercel.app)

## Stack

- Next.js (App Router)
- TypeScript
- NextAuth
- Postgres
- Tailwind CSS

## Run locally

```bash
git clone https://github.com/imiantalha/cms-dashboard.git
cd cms-dashboard
npm install
```

Copy the course `.env` values (database and auth secrets), then:

```bash
npm run dev
```
